# Daily workflow

1. Check local environment and API capabilities.
2. Run configured ATS scan.
3. Review work-authorisation results before fit scores.
4. Shortlist only after checking unresolved sponsor/visa items.
5. Generate a package from the appropriate resume track.
6. Review claim provenance and high-risk screening answers.
7. Approve the package.
8. Launch supervised autofill in Local Mode only.
9. Resolve any manual fields/CAPTCHA/login yourself.
10. Stop at `ready_to_submit`; the user clicks final Submit.
11. Record the submitted state only after that external human action occurred.
