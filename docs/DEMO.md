# Demo Walkthrough

Demo Mode uses deterministic synthetic data.

Suggested recruiter walkthrough:

1. Open **Dashboard** and note the sponsor-aware metrics.
2. Open **Discover Jobs**; Work Authorisation is displayed before Match.
3. Review a high-fit role and inspect route, evidence, confidence and unresolved checks.
4. Open **Prepare Application** and expand a generated claim's source-fact provenance.
5. Review screening answers and the optional cover letter.
6. Open **Autofill** and observe that Demo Mode is a simulation and final submission remains manual.
7. Approve the synthetic package and inspect the Applications tracker.

No login, candidate secret, live ATS access or real browser profile is required.
